## 三条不可动摇的原则

1. **知识包优先于视频** —— 知识包正确，展示形式才有意义
2. **证据优先于结论** —— 没有来源支撑的内容，不能包装成确定事实
3. **复用优先于重复生成** —— 深度切换、追问、关联探索尽量复用知识包

## 两个容易踩的坑（提前记下）

**① 改了 prompt 但输出没变**
缓存 key 必须包含 `prompt_version`，否则旧缓存会一直命中。见数据库文档「L1–L5 缓存」一节。

**② 知乎直答被当成独立证据**
直答和它引用的回答同源，`independence_key` 必须相同，否则会算出虚假的交叉验证。见架构文档「关键原则」一节。
