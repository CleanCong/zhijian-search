# 备选功能清单

> 用途：主路径（可运行体验链接 + 计划书）完成并通过验收之前，**任何人不得从本清单往外取任务**。
> 原则：不删除想法，只延后决策。每个备选项都有明确的「触发条件」，避免两件事——变成永远不做，或者第 10 天突然插队。

---

## 一、A 类 · 主路径完成后可做

拿到顺序：**OPT-01 → OPT-05 → OPT-02 → 其余**。同一时间只允许推进一项。

| 编号 | 功能 | 对应需求 | 价值 | 成本 | 触发条件（全部满足才可启动） |
|---|---|---|---|---|---|
| **OPT-01** | 知乎 OAuth 登录 | 人气奖 | 人气奖参与资格（2 队 × 2000 元），官方推荐接入 | 约 1 天 | ① 主线全部验收通过 ② 距离截止 ≥1.5 天 ③ **不登录也能跑完整流程**（硬性） |
| **OPT-05** | 用户偏好记忆 | 补「个性化」缺口 | 记住上次时间窗、屏蔽过的作者，提升创新度观感 | 约 0.5 天 | 主线验收通过 + 剩余 ≥1 天 |
| **OPT-02** | 重组资料 LLM 润色 | FR-12 的进阶分支 | 资料更通顺，能体现模型能力 | 约 0.5 天 | ① 拿到可用 API Key ② 本地拼接版已验证可用（润色只是可选按钮） |
| **OPT-04** | 观点矩阵独立视图 | FR-11 双视图 | 满足 PRD 的双视图要求 | 约 0.5 天 | 收到「三段式看不清对立关系」的真实验证反馈 |
| **OPT-06** | 分数构成浮层 | NFR-3 | 评委问「怎么算的」时能当场亮出来 | 约 0.3 天 | 答辩彩排中出现该问题 |
| **OPT-03** | 科普视频分镜 | OPT-8 | 多模态沾边，显得功能完整 | 1–2 天 | **仅在时间明显溢出时**；已知风险：它是 HTML 分镜不是真视频，被问一句就露 |
| **OPT-07** | 多品类判据库 | 产品化能力 | 赛后落地能力 | 3 天以上 | **本次不排期**，赛后事项 |

## 二、B 类 · 明确不做（记录原因，避免反复讨论）

| 编号 | 功能 | 不做的原因 |
|---|---|---|
| NO-01 | 管理后台 | 评委一次都不会点，对四个维度均无贡献 |
| NO-02 | 移动 App | 交不了安装包；官方要求网页公网可访问即可（注意：**响应式网页必须做**，这是两件事） |
| NO-03 | 自建注册与账号体系 | 无收益，OAuth 已覆盖；自建账号还要处理密码安全 |
| NO-04 | 内容社区 / 评论 | 冷启动是另一个量级的问题，与「一次决策」场景不符 |
| NO-05 | 爬虫抓取内容 | 违反平台规则，且已有合规开放接口；走官方 API 本身是优势 |
| NO-06 | 订阅 / 实时推送 | 用户是一次性决策，没有回访理由，做订阅是给自己造需求 |
| NO-07 | 多语言 | 与所选赛道（AI × 知识与探索）无直接关系，且翻译会引入新的判断题 |

## 四、取用规则

1. 从本清单取任务前，先过三问：
   - 对「AI 场景价值」（40%）有贡献吗？
   - 会不会给主流程增加失败点？
   - 有足够时间做深吗？（**做不深的功能比没有更糟**）
2. 任何从 A 类取出的项，必须在当日 22:00 同步里报备，且当周不再插入第二项。
3. D12–D13 两天为缓冲期，**任何情况下不从本清单取任务**。
4. 出现以下任一情况，本清单整体冻结至提交后：主线未跑通、部署未成功、计划书未定稿。
